# Changelog archive

Status: historical index; the original detailed archive is preserved in Git.
Audience: users and maintainers looking up releases before v0.4.0.

For current changes, read the [changelog](https://github.com/wavect/semaprax/blob/main/CHANGELOG.md).
For a quick release overview, read the [changelog summary](CHANGELOG-SUMMARY.md).

The former 5,342-line archive mixed pre-v0.4 release notes with an old
“Unreleased” queue. It is not a useful guide to current behavior. Its exact
bytes remain available at the [immutable archive snapshot](https://github.com/wavect/semaprax/blob/c4fa119d93df293e50d05dba23310305caf597c2/docs/CHANGELOG-ARCHIVE.md).
That snapshot contains the v0.3.5, v0.2.0, and v0.1.0 notes; search within it
for the version or feature you need. Historical entries describe their own
commit and evidence, not current `main` or current product support.
