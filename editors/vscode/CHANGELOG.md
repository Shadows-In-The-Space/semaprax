# Changelog

All notable changes to the Semaprax Visual Studio Code extension are documented here.

## 0.1.0

Initial Marketplace-ready preview release.

### Added

- `.spx` syntax highlighting and language configuration
- compiler diagnostics on save and explicit project checks
- semantic declaration navigation, caller discovery, and code lenses
- ownership, contracts, effects, documentation, and cleanup-plan inspection
- saved-source candidate sessions and immutable source-diff previews
- typed-intent workflows and compiler-admitted diagnostic repairs
- typed-hole planning, checked fill suggestions, and explicit completion
- candidate interpreter-test tasks with cancellation
- agent-definition inspection and trace/evidence transcript support
- Marketplace metadata, icon, packaging exclusions, license, and public-facing README

### Safety boundaries

- no compiler discovery from workspace settings
- no automatic downloads
- no shell invocation for compiler commands
- no editor commands for build, commit, approval, or publication
